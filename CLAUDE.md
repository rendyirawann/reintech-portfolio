# REIN-TECH Portfolio — Agentic Development Rules

This project follows the **Superpowers** and **Everything Claude Code (ECC)** methodologies for high-performance, high-fidelity development.

## 🛠 Tech Stack
- **Framework**: Laravel 12 (Blade, Tailwind CSS v4)
- **Animation**: GSAP v3.15.0, Canvas API
- **Build Tool**: Vite 6

## 🚀 Agent Skills & Methodology
- **Design Intelligence**: Powered by `ui-ux-pro-max-skill`. Prioritize high-fidelity, premium aesthetics (Glassmorphism, Liquid Glass, Aurora UI).
- **Workflow**: Follow `superpowers` brainstorming -> planning -> implementation (TDD).
- **Optimization**: Adhere to `ECC` performance rules for Laravel and TypeScript.

## 📜 Development Guidelines
- **Canvas Animations**: Maintain the 6-canvas system (Preloader, Hero, About-DNA, Projects-Matrix, Services-Circuit, Contact-Wormhole).
- **Bleeding Edge Layout**: Always use the 100% full-width layout with `.section-inner` containers (1400px).
- **TDD**: Write tests for critical logic before implementation.
- **Git**: Follow semantic commit messages.

## 📂 Project Structure
- `.claude/rules/`: Global and language-specific rules.
- `.claude/skills/`: Integrated agentic skillsets (Superpowers, UI-UX Pro Max, ECC).
- `resources/js/app.js`: Main animation logic.
- `resources/css/app.css`: Design system and layout tokens.
